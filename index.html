Privacidad y límites

Las imágenes se envían temporalmente al servicio de Render para detectar la cara con buffalo_l; el servidor no las guarda. La deformación y composición finales se ejecutan en el navegador. El modelo de InsightFace se ofrece para investigación no comercial; revisa su licencia antes de publicar la app para otros usos.

No uses imágenes de otras personas para engañar o hacer pasar el resultado por auténtico. Utiliza fotos propias o con permiso.
